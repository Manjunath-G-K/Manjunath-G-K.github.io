## ✅ Handling Image Formats (PNG, JPG, WebP)

If your certificate files are **images** instead of **PDFs**, just do the following:

1. Copy the image files into this directory (`Portfolio/assets/certificates/`).
2. Rename them to match the table above, but use their natural extension (e.g. `infosys-internship-6.0.png` or `infosys-internship-6.0.jpg`).
3. Open `index.html` and search for the certificate's link wrapper `href`.
4. Update the extension from `.pdf` to `.png` or `.jpg` to match your file.
   * *Example:* Change `<a href="assets/certificates/infosys-internship-6.0.pdf" ...>` to `<a href="assets/certificates/infosys-internship-6.0.png" ...>`.
